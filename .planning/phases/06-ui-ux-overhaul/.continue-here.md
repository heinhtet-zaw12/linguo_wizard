## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Migration script dropping .withValues() args | The font migration regex captured `AppColors.textMuted.withValues` but dropped `(alpha: 0.4)` — left broken `.withValues)` references | advisory | After any automated migration, grep for broken patterns (`withValues)`, `const AppTextStyles`) before committing |
| const on non-const static methods | Migration replaced `const TextStyle(fontFamily: 'Quicksand')` with `const AppTextStyles.bodyMedium()` — but static methods aren't const-constructable | advisory | Never wrap AppTextStyles.* calls in const — they're factory methods, not constructors |
